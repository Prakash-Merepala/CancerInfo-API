# Hosted API access and usage

## Basic subscription

Owner-confirmed configuration and screenshots, October 2, 2026:

| Setting | Basic plan |
| :--- | :--- |
| API subscription price | $0 per month |
| Request allowance | 1,000 requests per month |
| Request quota behavior | Hard limit: further requests are blocked until the quota period resets |
| Rate limit | 10 requests per minute |
| RapidAPI Bandwidth Platform Fee | Pricing screen shows 10,240 MB per month, then $0.001 per additional MB |

The $0 price refers to the API subscription. RapidAPI separately charges the consumer for bandwidth above the included allowance. A hard request quota does not cap bandwidth charges. Review the [current RapidAPI Pricing tab](https://rapidapi.com/PrakashMerepala/api/cancer-info-api/pricing) before subscribing or using the API.

These are the owner-reported plan settings, not proof of gateway enforcement or an availability commitment. Backend request limits are separate. The listing remains a private launch draft until release acceptance and publication approval are complete.

## Consumer-facing pricing wording

The Basic plan has a $0 monthly API subscription, with 1,000 requests per month and a hard quota limit, plus a rate limit of 10 requests per minute. RapidAPI bandwidth platform charges may apply separately. See the current Pricing tab for allowances and charges before using the API.
